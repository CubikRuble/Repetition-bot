# MovieBot — Telegram-бот «Фильмы на потом»

## Задача 3: поиск на Кинопоиске и подбор фильма

Бот ищет фильмы на Кинопоиске и показывает три первых результата, каждый с номером на отдельной
строке. Выбранный фильм можно сохранить в список «посмотреть позже» по номеру из последнего поиска
(бот помнит последний поиск каждого пользователя). 

Команда `/add` удалена: её функции перешли
к связке `/find` и `/save`. Один и тот же фильм нельзя добавить дважды, а одноимённые фильмы
разных лет считаются разными. 

Бот также советует фильм с наивысшим рейтингом из списка пользователя,
при желании только вышедший после указанного года.

### Команды

| Команда | Что делает |
|---|---|
| /start, /help | показывает справку |
| /find <название> | показывает три первых результата поиска на Кинопоиске |
| /save <номер> | добавляет в список фильм с этим номером из последнего поиска |
| /remove <название> | удаляет фильм из списка |
| /list | показывает список |
| /pick [после <год>] | советует фильм с наивысшим рейтингом из списка |

Регистр и лишние пробелы в командах и названиях не важны.

### Примеры диалогов

**Пример 1. Поиск и добавление фильма**
П: /find Матрица
Б: Найдено:
1. Матрица (1999), рейтинг 8.5
2. Матрица: Перезагрузка (2003), рейтинг 7.2
3. Матрица: Революция (2003), рейтинг 6.8
   П: /save 1
   Б: Фильм «Матрица» (1999) добавлен в список
   П: /list
   Б: 1. Матрица (1999)

**Пример 2. Подбор из списка**
П: /find Аватар
Б: Найдено:
1. Аватар (2009), рейтинг 7.9
   П: /save 1
   Б: Фильм «Аватар» (2009) добавлен в список
   П: /pick
   Б: Советую посмотреть: Матрица (1999), рейтинг 8.5
   П: /pick после 2000
   Б: Советую посмотреть: Аватар (2009), рейтинг 7.9

**Пример 3. Ошибки**
П: /save 1
Б: Сначала найдите фильм: /find <название>
П: /find Квантовый ляпсус
Б: Ничего не найдено
П: /find Матрица
Б: Найдено:
1. Матрица (1999), рейтинг 8.5
2. Матрица: Перезагрузка (2003), рейтинг 7.2
3. Матрица: Революция (2003), рейтинг 6.8
   П: /save 7
   Б: В результатах поиска нет фильма с номером 7
   П: /pick после 2030
   Б: В вашем списке нет подходящих фильмов

## Как устроен проект

- logic/BotLogic — разбирает сообщения и формирует ответы; не зависит от Telegram.
- catalog/MovieCatalog — интерфейс каталога фильмов; catalog/KinopoiskCatalog — поиск через kinopoisk.dev.
- catalog/Movie — фильм: идентификатор Кинопоиска, название, год, рейтинг.
- storage/WatchlistStorage — интерфейс хранилища; storage/JdbcWatchlistStorage — хранение в SQLite (файл watchlist.db).
- telegram/TelegramBot — принимает и отправляет сообщения Telegram.
- Main — связывает части и запускает бота (токены в переменных окружения BOT_TOKEN и KINOPOISK_TOKEN).
