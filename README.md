# FirstBot — Telegram-бот «Фильмы на потом»

## Задача 2: список «посмотреть позже»

Бот ведёт для каждого пользователя отдельный список фильмов «посмотреть позже»:
добавляет и удаляет фильмы по названию и показывает список. Диалоги разных пользователей
независимы, данные сохраняются в базе SQLite (через JDBC) и не пропадают после перезапуска бота.
Код разделён на три слоя: логика диалога, хранилище, Telegram-адаптер.

### Команды

| Команда | Что делает |
|---|---|
| /start, /help | показывает справку |
| /add <название> | добавляет фильм в список |
| /remove <название> | удаляет фильм из списка |
| /list | показывает список |

Регистр и лишние пробелы в названии не важны: «матрица» и «МАТРИЦА» — один и тот же фильм.

### Примеры диалогов

**Пример 1. Обычная работа**
П: /add Матрица
Б: Фильм добавлен
П: /add Дюна
Б: Фильм добавлен
П: /list
Б: 1. Матрица 2. Дюна
П: /remove матрица
Б: Фильм удалён
П: /list
Б: 1. Дюна

**Пример 2. Ошибки**
П: /add
Б: Укажите название после команды, например: /add Матрица
П: /add Матрица
Б: Фильм добавлен
П: /add МАТРИЦА
Б: Этот фильм уже есть в списке
П: /remove Аватар
Б: Такого фильма нет в списке
П: привет
Б: Не понял вас. Список команд: /help

**Пример 3. Два пользователя**
Пользователь 1: /add Матрица
Бот: Фильм добавлен
Пользователь 2: /list
Бот: Список пока пуст. Добавьте фильм командой /add <название>

## Как устроен проект

- logic/BotLogic — разбирает сообщения и формирует ответы; не зависит от Telegram.
- storage/WatchlistStorage — интерфейс хранилища; не зависит от логики диалога.
- storage/JdbcWatchlistStorage — хранение в SQLite (файл watchlist.db).
- telegram/TelegramBot — принимает и отправляет сообщения Telegram.
- Main — связывает части и запускает бота.
